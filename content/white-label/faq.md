# Questions buyers ask

### Do I get the source code with a licence?

Not for the dashboard or its backend; those change hands only with a buyout. The plugin is GPL, so its source comes
with the copy we build for you.

### Can you sell Empora to someone else after I buy a licence?

Yes, until someone buys it outright. A licence is not exclusive; a buyout is.

### Is there a white-label mobile app?

Not yet. The Android app is built but has not been released, so no licence includes it today.

### What happens when the included updates end?

Your deployment keeps running on the last version we shipped. Nothing is switched off, and a renewal starts the
updates again.

### How does anyone know a deployment holds a licence?

Each deployment serves a small licence file and carries its key. Anyone can check either on the
[verify page](https://empora.aoneahsan.com/verify-license).

### Where are the full terms?

The plain-words version is the [licence terms page](https://empora.aoneahsan.com/white-label/license-terms); the
full text, payments included, is section 15 of the
[Terms of Service](https://empora.aoneahsan.com/terms#white-label-licences-and-buyouts).
